# Code City 视觉候选方案

本轮仅生成概念效果图，等待用户选定视觉方向后再开始开发。任务书原件保留。

## 共用约束

- 以 1200 × 420 比例的 README 横幅为首要展示对象。
- 每套方案同时展示横幅与未来交互页面的视觉方向。
- 黑蓝背景、等距视角、低多边形建筑、克制的语言配色。
- 约 30 栋建筑、4 个示例仓库；所有指标、文件和名称均为假数据。
- 文件对应建筑，代码行数对应高度，仓库对应城区，测试使用绿色屋顶，文档使用图书馆和广场。
- 图片为 AI 生成的概念图，细节和文字以正式实现为准。成品运行时仍遵守任务书要求，不调用 AI。

## A · 午夜天际线 / Midnight Skyline

连续城市底座与紧凑街区，强调远看时清晰的天际线。青蓝色为主，少量琥珀和紫色作为辅助。标题在横幅左侧，城市在右侧；页面使用轻量仓库列表与文件浮层。

适合：README 展示优先，希望第一版与任务书视觉方向最接近。

## B · 浮岛群城 / Repository Islands

每个仓库位于独立薄平台，平台之间保留明显间隙，用简洁连接通道组织多个项目。仓库标签贴近各自底座。页面以大画布和仓库选择器突出多仓库探索。

适合：突出个人主页上的多个代表项目，强调城区之间的辨识度。

## C · 代码街区图 / Code District Map

更高的等距视点、规整道路与清晰地块边界，让目录结构易读。建筑整体较低，选中的文件有清楚的描边和简洁标注。页面以目录树、城市和文件详情组织信息。

适合：偏重单仓库分析、文件定位和结构解释。

## 选择与实施范围

可以选择 A、B、C，也可以指定一种城市风格搭配另一种页面布局。

选定后先按任务书阶段 0 实现固定假数据的 SVG 横幅、预览页面和下载功能。概念图中的高级交互属于后续阶段，不代表本轮已经实现。

生成方式：内置 imagegen。完整提示词见 prompts.json。
